# CaseComp — Investment Data Quality

## Objective
Design and demonstrate a data quality architecture
for a front-to-back investment platform.

## Project structure
- notebooks/: Data exploration and analysis
- src/: Reusable data quality checks
- dashboard/: Interactive dashboard
- tests/: Automated tests
- data/: Local datasets

## Team workflow
Each contributor should commit work with a
descriptive message and coordinate notebook changes.
